## Task 5.1: Terminal Navigation

### Exercise 1: Basic Navigation

| Command | What it does |
|---|---|
| `pwd` | Displays the current working directory. |
| `ls` | Lists files and directories. |
| `cd ~/Documents` | Navigates to the Documents directory. |
| `cd ..` | Moves one directory level up. |
| `cd ~` | Returns to the home directory. |

### Exercise 2: Creating Project Structure

| Command | What it does |
|---|---|
| `mkdir my-project` | Creates the main project directory. |
| `mkdir -p my-project/src/css my-project/src/js my-project/src/images` | Creates nested directories. |
| `mkdir my-project/docs my-project/tests` | Creates documentation and testing directories. |
| `touch my-project/README.md` | Creates the README file. |
| `ls -R my-project` | Displays the project structure recursively. |

## Task 5.2: File Operations

### Exercise 1: Creating and Editing Files

| Command | What it does |
|---|---|
| `touch index.html` | Creates an HTML file. |
| `cat index.html` | Displays file contents. |
| `vi index.html` | Opens the file in Vim for editing. |
| `cp index.html backup.html` | Copies the HTML file. |
| `mkdir docs` | Creates a docs directory. |
| `mv backup.html docs/` | Moves the backup into docs. |
| `mv index.html home.html` | Renames the HTML file. |
| `rm home.html` | Deletes the file. |

### Exercise 2: Working with Directories

| Command | What it does |
|---|---|
| `cp -r src/ src-backup/` | Copies a directory and its contents. |
| `mkdir archive` | Creates an archive directory. |
| `mv src-backup/ archive/` | Moves the backup directory into archive. |
| `rm -r archive/src-backup` | Removes the copied directory and its contents. |
| `rmdir archive/` | Removes the now-empty archive directory. |
| `rm -r archive/` | Removes a directory recursively (demonstrated after recreating it). |

## What I Learned

- How to navigate directories using the terminal.
- How to create files and nested folders.
- How to view, copy, move, rename and delete files.
- The difference between `rm`, `rm -r` and `rmdir`.
- How to organize project files using terminal commands.
