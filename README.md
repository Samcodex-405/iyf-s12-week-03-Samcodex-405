## Shell Script Automation

This repository includes `new-project.sh`, a Bash script that automates project creation.

The script creates a standard project structure containing:

- `src/` for source code.
- `css/` for stylesheets.
- `js/` for JavaScript.
- `images/` for project images.
- `docs/` for documentation.
- `tests/` for testing files.

To execute the script:

```bash
chmod +x new-project.sh

bash new-project.sh my-awesome-app
```

## Git Workflow

This project uses Git for version control.

The commit message format follows the course convention:

`Type: description`

Examples:

- `Add: Week 2 portfolio as the starting point`
- `Style: add navigation hover underline`
- `Fix: correct responsive breakpoint for projects grid`
- `Docs: add terminal log`
